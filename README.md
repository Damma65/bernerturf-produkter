# Berner Turf Produkter

WordPress-plugin för bernerturf.com: produktkatalog, produktsida, import från Excel/SharePoint och översättning med Claude.

Nya versioner publiceras genom att `update.json` och zip-filen i `releases/` uppdateras. Sajten visar dem under Tillägg, där en administratör installerar dem för hand. Automatisk installation är av och slås bara på med `define( 'BTP_ENABLE_AUTO_UPDATE', true );` i wp-config.php.

Se `readme.txt` för funktioner och ändringslogg. Inga hemligheter eller kunddata finns i koden; API-nycklar läggs in i WordPress.
